**Why the spec changed.**
- The `plan` step wrote the specs at 23:15:37. Deli Counter generated
  `shell.glb` at 23:16:03.
- With no lot library, the building a site places is generated by the Deli
  Counter job the assembly depends on. So `site_variation.shell_footprint`
  had nothing to read, and the plate and spacing fell back to
  `DEFAULT_FOOTPRINT`, 48 x 48 m.
- The art run planned after the shell existed, measured 40 x 30 m, and wrote
  a different site.
- The lock refused it correctly: the site that would ship is not the site
  that was judged.

**Old, and newly caught.** The measurement dates from 27 July, and this
mission exported in September (cold run 9005, export exit 0), so the drift
most likely existed then. The lock only began guarding site data later; the
export's own warning on another test reads "protects no site data -- every
signature it checks is filled from the Deli side".

**Fixed in Level Factory 0.144.2:** the site spec is written again at
dispatch, once the job's dependencies have built what it measures.
county_hospital_001 runs again on it. restaurant_row_001 and
warehouse_yard_001 take the same no-library path, and run after the fix.
