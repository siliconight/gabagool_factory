The walker, 2026-10-10, on the six-option edge menu framed on cold run
9219's walk copy (`docs/findings/edge_menu/README.md`): "I prefer E, but we
should have multiple different versions depending on the level..."

- **E** = `fence` + `glow` + `houses` + `tower`: a fenced lot backing onto
  rowhomes, a water tower as the landmark. I had recommended D (trees).
- **Per-level variety is part of the ask.** One backdrop everywhere is
  wrong; the surroundings should follow the level (archetype / site_shape /
  brief), e.g. a street block backs onto rowhomes (E), a yard onto rail or
  industry, a roadside strip onto a tree belt (D).

**Why:** walker taste overrides my recommendation ([[walker-taste-overrides-art-budget]]);
and a backdrop that is the same on every level reads as generated, which
is the "good" gate (roadmap 18) this menu exists for.

**How to apply:**
- Build E first in the owning tools (Lux glow per time of day; Lot + Zoo
  fence at the plate edge, one long run a side; Zoo backdrop rowhome kit
  with real rooflines, since the mockup's blocks only read by their
  windows; Zoo water tower + Lux beacon).
- Make the selection a per-level recipe ("surroundings") with E as the
  street-block default and D/others as alternatives; a brief may name it.
- Price each part as the menu was priced: fixed stations, two controls.
- Nothing from `docs/findings/edge_menu/edge_proto.gd` ships as is; it is
  the mockup.
