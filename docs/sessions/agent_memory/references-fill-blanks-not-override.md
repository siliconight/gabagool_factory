The game is a fictional world. Reference material the walker supplies -- e.g. `1990s_US_Lighting_Art_Direction_Guide.md` (2026-09-29, in their Downloads) -- is for filling in things nobody has decided yet, not for correcting what already looks/feels good.

**Why:** the walker, sending that guide: "we are a fictional world, so these are meant to help fill in blanks, not necessarily change what we already think looks/feels good."

**How to apply:** when a reference disagrees with a shipped look (e.g. the guide says avoid constant flicker; every fluorescent rig here flickers), report it as an option for the walker, don't change it. Use references freely to answer open questions and to spec new things (a missing sign, a warm counter accent). See [[walker-taste-overrides-art-budget]], [[performance-beats-graphics]].
