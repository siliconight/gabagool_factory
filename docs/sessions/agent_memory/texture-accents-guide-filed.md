The walker's "Second-Pass Texture Accents for Stylized Realism" guide (Blender
node group over an accepted base material; masks by cause; bake to PBR maps)
is filed at `docs/reference/BLENDER_SECOND_PASS_TEXTURE_ACCENTS_GUIDE.md`, and
two comps of whitewash over brick worn by weather (another studio's map, read
for technique only) at `docs/reference/PAINTED_BRICK_WEAR_COMPS.md`. Roadmap
237 places it: tier A = tileable accent layers in Pixelcoat pack recipes
(`pixelcoat_build`, free at runtime; `recipe.cavity_grime` is the seed); tier
B = cause-driven masks generated by the tool that knows the cause (Zoo recipes,
DC slots, Lot furniture) in the part's vertex colour, read by the SHARED
material (the `Wear` channel reaches Godot on both material paths; B2 = a
worldskin-installed shader for chips/runoff, priced like the CRT `next_pass`);
tier C = the full pass + Cycles bake for hero uniques at library time, one or
two a level. **First recipe (the comps):** a `brick_whitewash` wall pack, the
plinth band (open: a base_course grown, or a ground-storey pack with a
storey-tall tile), a rust `streak` floater under every wall box merged into the
side's dressing, the exposure value in `Wear`.

**Why:** the walker wants the guide used "where appropriate"; the perf contract
forbids a material a placement and GL Compatibility has no decals, so the pass
cannot be applied as written to every surface.

**How to apply:** route any surface look item by tier; never runtime decals,
never a unique texture an instance, never Patina's greybox pass; the base must
be accepted (the walker's eye) before accents. Queue: after roadmap 181 and the
level-creation work (the walker's priority), tier A first.
